# 首页 UI 配色修改设计方案

本项目旨在将“Token Insight”本地 AI 仪表盘的浅色模式（Light Mode）配色体系重构为类似 Shopeers 的**素雅冷灰色背景、纯白卡片、皇家蓝（Royal Blue）高亮与薄荷绿辅助点缀**的扁平化现代 SaaS 视觉风格，而不改变现有布局。深色模式（Dark Mode）将保持原样不作改动。

---

## 1. 视觉设计调性定义

* **设计风格**：极简现代扁平化 SaaS 风格（Minimalist Flat SaaS）
* **背景基调**：中性偏冷的极浅灰蓝色背景（替换原有的略微偏暖、含渐变斑点的背景）
* **卡片质感**：纯白卡片（`#ffffff`），带浅灰色精细边框，去掉原本的磨砂玻璃半透明质感，确保边缘利落清晰
* **品牌与激活主色**：高饱和皇家蓝（`#2563eb`），用于选中、激活项及主要按钮
* **图表配色**：以皇家蓝为核心折线与柱状图颜色，配合薄荷绿与琥珀黄作为多维度辅助色

---

## 2. 全局样式调整设计 (`src/index.css`)

修改仅作用于 `:root`（浅色模式）下的 CSS 变量及特定布局类，不影响 `.dark` 作用域。

### 2.1. CSS 变量调整

| 变量名 | 原有值 (Light) | 修改后 (Light) | 设计用意 |
| :--- | :--- | :--- | :--- |
| `--bg-app` | `#f8fafc` | `#f4f6f8` | 替换为稍冷偏灰的背景，以凸显纯白卡片 |
| `--card-bg` | `rgba(255, 255, 255, 0.75)` | `#ffffff` | 卡片由半透明改纯白，去除毛玻璃磨砂感 |
| `--card-border` | `rgba(148, 163, 184, 0.15)` | `rgba(226, 232, 240, 0.8)` | 浅灰色精细边框描边，使扁平化设计更显精致 |
| `--card-border-hover` | `rgba(6, 182, 212, 0.4)` | `rgba(37, 99, 235, 0.25)` | 悬浮时边框呈现微蓝色，与皇家蓝主色调呼应 |
| `--neon-blue` | `#2563eb` | `#2563eb` | 皇家蓝（保持一致），作为首选主高亮色 |
| `--neon-green` | `#16a34a` | `#10b981` | 调整为更亮丽的薄荷绿/翠绿，用于正向趋势 |
| `--neon-cyan` | `#0891b2` | `#0ea5e9` | 调整为明亮的天空蓝/浅青色 |
| `--neon-orange` | `#ea580c` | `#f59e0b` | 调整为更柔和的琥珀橘黄色 |

### 2.2. 特殊容器与背景类调整

1. **`.dashboard-header-bg`（顶部渐变背景）**：
   * **修改前**：包含青色、橙色等多色发光径向渐变，色彩斑斓。
   * **修改后**：改为纯净的由白到淡灰的线性渐变，显得高级而素雅：
     ```css
     .dashboard-header-bg {
       background: linear-gradient(180deg, #ffffff 0%, #f8fafc 100%);
       border-bottom: 1px solid rgba(226, 232, 240, 0.8);
     }
     ```

2. **`.kpi-blue`, `.kpi-cyan` 等（指标卡片背景）**：
   * **修改前**：带有各自色系的彩底微渐变（例如 `from-blue-50 via-white to-cyan-50/70`）。
   * **修改后**：在浅色模式下统统修改为纯白色底，去掉背景彩底，仅保留细边框。仅在 `.dark` 作用域下保持原彩底设计：
     ```css
     .kpi-blue, .kpi-cyan, .kpi-orange, .kpi-green, .kpi-purple, .kpi-slate {
       background: #ffffff;
       border-color: rgba(226, 232, 240, 0.8);
     }
     ```

## 3. 图表组件配色调整 (`src/components/charts/`)

为了使图表系列的配色也与图片中“蓝色折线+蓝色柱状+绿色圆环”等冷调统一，我们需要覆写图表的色板配置：

1. **全局 ECharts 主题及色板更新**：
   在图表组件中检测到 `theme === 'light'` 时，使用全新冷调色板配置：
   ```typescript
   const LIGHT_PALETTE = [
     '#2563eb', // 1. 皇家蓝 (Royal Blue)
     '#10b981', // 2. 薄荷绿 (Mint Green)
     '#0ea5e9', // 3. 浅青色 (Light Cyan)
     '#6366f1', // 4. 睿智靛蓝
     '#8b5cf6', // 5. 科技紫
     '#f59e0b', // 6. 琥珀黄
     '#14b8a6', // 7. 薄荷绿/翠绿
     '#db2777', // 8. 柔和粉
   ];
   ```

2. **具体图表适配**：
   * **`DailyTrendChart.tsx`**：
     * 浅色模式下首选色板替换为皇家蓝及绿色等冷调。
     * “推理 Token” 折线图改为皇家蓝或靛蓝，折线下方填充极为淡雅的皇家蓝渐变面积。
   * **`PerformanceChart.tsx`**：
     * 将 Latency 和 TPS 曲线调和为皇家蓝（#2563eb）与薄荷绿（#10b981）。
   * **`ProjectTrendChart.tsx` & `SourceTrendChart.tsx`**：
     * 分类图表使用 `LIGHT_PALETTE` 色板，使主数据类别（排名第一、第二）默认展示皇家蓝和薄荷绿。

---

## 4. 验证与回归测试

1. **样式确认**：启动本地开发服务器，比对浅色模式下整体背景色是否与图片一致，各个组件是否为纯白无磨砂透光，头部是否无五彩斑点。
2. **深色模式一致性**：确认切换至深色模式后，旧有的磨砂玻璃与深蓝/霓虹渐变完全保留。
3. **图表显示验证**：确认折线图、柱状图在浅色模式下以皇家蓝和薄荷绿作为主色，且折线阴影渐变没有高亮度发光感。
