# 诊断技能上传显示描述设计规约

本文档定义了在上传自定义 AI 诊断技能规范时，解析并显式呈现技能名称及描述的技术实现方案。

## 1. 背景与现状

目前用户在“AI 复盘与治理中心” -> “第四步：启用 AI 诊断技能规范” 中点击“管理技能”并上传自定义技能包时：
- 后端成功上传后仅返回 plain text `技能安装成功`。
- 前端仅默默刷新列表，没有即时呈现当前上传成功的是哪个技能、它的描述是什么。
- 此外，如果上传的技能包 `SKILL.md` 中没有严格定义 YAML Frontmatter 格式的 `description`，或者没有 Frontmatter，技能列表中会显示为“暂无描述信息”。

## 2. 拟议设计

### 2.1 后端解析增强 (`review.rs`)

1. **更具鲁棒性的技能信息解析 (`parse_skill_md_frontmatter`)**
   - 保持现有从 YAML Frontmatter 解析 `name` 和 `description` 的逻辑。
   - **名称兜底**：若 YAML Frontmatter 中没有 `name`，则遍历 markdown 内容，提取第一个 `# <标题>` 作为技能名称；若依然为空，则 fallback 到文件夹名。
   - **描述兜底**：若 YAML Frontmatter 中没有 `description`，则自动提取正文中第一个非空、非 Markdown 格式元素（不以 `#`, `>`, `-`, `*`, `+`, `` ` ``, `<`, `---` 开头）的段落行作为技能描述（取前 300 字符），防止显示为“暂无描述信息”。

2. **重构上传 API 响应格式 (`handle_upload_skills`)**
   - 不再返回 `技能安装成功` 纯文本。
   - 校验并保存成功后，重新解析刚上传的所有自定义技能的 `SKILL.md`，将这些技能封装为 `Vec<SkillInfo>`，并以 `application/json` 编码返回给前端。

### 2.2 前端反馈增强 (`SkillManagerModal.tsx`)

1. **上传成功状态管理**
   - 引入 `successSkills` 状态，类型为 `Skill[]`。
   - 当上传成功，解析 API 返回的 JSON 列表并存入 `successSkills`。

2. **上传成功悬浮横幅**
   - 在拖拽上传区下方/技能列表上方，展示绿色的玻璃拟态提示框。
   - 详细列出当前成功上传的每一个技能的**名称**和**技能描述**。
   - 允许用户手动点击右上角 `✕` 关闭该提示。
   - 在开始新一次上传或关闭模态框时，重置此状态。
